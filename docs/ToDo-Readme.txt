
-- ToDo Application

This is a simple ToDo application built with Node.js/Express.js and DynamoDB utilizing AWS API Gateway and Lambda Functions.
Use NPM START to run.

-- Prerequisites

* Node.js (version 14.x or later)
* npm (version 6.x or later)

-- Getting Started

These instructions will help you set up the project on your local machine and start running it.

1.  Navigate to the project directory = "project04"
2.  Install npm - npm install
3.  Start the express server - npm start
4.  Open browser to "http://localhost3000"

-- API Endpoints

* Retreive all tasks = "GET /api/tasks"
* Add new tasks = "POST /api/tasks"
* Delete tasks by task ID = "DELETE /api/tasks/:id"
